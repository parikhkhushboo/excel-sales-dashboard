
# Interactive Sales Analysis Dashboard – Excel

## Project Overview
Developed an interactive Sales Analysis Dashboard using Microsoft Excel to analyze sales performance and identify important business trends.

## Dataset
- 2,000 sales records
- Order ID and Date
- Region and Sales Channel
- Customer Type
- Product Category and Product
- Salesperson
- Quantity, Unit Price, Discount and Revenue

## Key Features
- Sales performance analysis
- Revenue and quantity tracking
- Region-wise sales analysis
- Product category analysis
- Monthly sales trend analysis
- Interactive PivotTables and charts
- Slicers and date timeline for filtering

## Tools & Technologies
- Microsoft Excel
- PivotTables
- PivotCharts
- Excel Slicers
- Data Cleaning
- Data Visualization
